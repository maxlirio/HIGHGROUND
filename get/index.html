HIGHGROUND

The Realm

Our family's kingdom. It runs day and night, and your house holds even while you're away. You need the game and the invite code you were sent.

Windows

Download for Windows
  1. Open HIGHGROUND-Windows.exe from your Downloads.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway. (The game isn't from a big publisher, so Windows doesn't recognise it yet.) If your browser asks whether to keep the file, choose Keep.
  3. Paste your invite code and click Enter the realm. That's it. Next time, open HIGHGROUND from your desktop or Start menu.

Mac

Download for Mac
  1. Open the download so it unzips, then drag HIGHGROUND into your Applications folder.
  2. The first time, right-click HIGHGROUND and choose Open, then Open again. On newer Macs, if it only offers Done or Move to Trash, click Done, go to System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. Paste your invite code and click Enter the realm. After that it opens like any other app.

Linux

Download for Linux
  1. Unpack the download, then run ./install.sh in the HIGHGROUND folder (no root needed).
  2. Open HIGHGROUND from your app menu, or run highground in a terminal. It opens in your own browser's app window (Chrome, Chromium, Brave or Edge give the best full-window result).
  3. Paste your invite code and click Enter the realm. That's it.

No download? The game also runs in a web browser: play in the browser. The game updates itself; you never need to download it again.
